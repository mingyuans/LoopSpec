# 实施代码安全复审

## 结论与范围

针对本次 V1/V2 实现、内置资源、Skill 源、CLI 接入和测试进行源码复审，结合 936 项完整回归及专项验证，未发现本次交付范围内仍需阻塞实施完成的已知问题。本记录是实施阶段的自查，不是第三方安全认证，也不替代真实项目的代码安全审查。

设计阶段的 security/pass.md 保留原结论；它本身不作为代码已通过测试的证明。

## 检查与修正

- 不可信配置与资源：新入口使用有界、无别名和重复键的 YAML 解析与严格模型。显式 Plan/Profile 创建不经过旧配置报错路径，默认模板选择也使用安全读取；错误不回显原始配置字段。补充三种新建方式的敏感测试标记不回显测试。
- 路径与文件身份：资源、产物与控制文件使用相对路径校验、目录描述符和 no-follow 打开。拒绝路径穿越、链接资源、特殊文件、跨实例输出冲突及输出占用控制路径；读写期间复核身份。不以先前 resolve 的结果替代打开时检查。
- 快照与审批：摘要覆盖规范化 Plan、资源哈希、实例、恢复规则和固定基线。资源持久化只使用已编译缓存；暂存校验后才切换活动指针。日志在激活前建立，失败不留下可执行的部分计划。完整但未激活的残留下一版快照只在校验后复用或移动到唯一非活动目录保留，不覆盖活动修订或待恢复事务。
- 恢复与预算：只接受有效 Gate FAIL，缺产物、空白摘要、过期证据和系统错误不充当 FAIL。一次失败只有一个最近处理者，引用共享预算，父级 reset 不清零历史。复审补充禁止向冻结/有历史 Gate 插入新处理者，防止改变优先级或取得额外预算。
- 归档与事务：移动源限于已编译产物和明确 Gate 控制文件；目标固定在本需求 Attempts/修订目录，带原文件哈希校验。事务中断阻塞导航，可 inspect/resume；测试覆盖移动、激活和收尾中断。业务代码不随返工恢复或删除。
- Git 输入：以参数数组运行固定只读子命令，不使用 Shell；清理 Git 环境注入，禁用 hooks、外部 diff、fsmonitor、全局配置和惰性拉取，不运行 textconv/过滤器。输出只提供路径、模式和摘要，不输出业务文件正文。NUL 清单、单文件/累计读取上限及双扫描一致性检查覆盖创建前脏改动、后续提交、Index、工作树、新文件、删除、模式和重命名两端；不支持输入保守拒绝。
- 代码证据：begin/record 的轮次是一次性标识，不是认证凭据。证据绑定具体 Gate、Plan、基线、范围、输入摘要和报告哈希；记录前后复核代码，不采信报告自报的范围摘要。手写 PASS 不通过代码/系统保障 Gate。
- 全量保障：规则要求取并集，证据不跨范围或实例混用；未知路径与缺失/过期覆盖阻止通过。最终 Assurance 必须覆盖全部分支，所有代码 Gate 必须先于它。安全扩张只增加诊断建议的修复工作，原 QA 依赖全部新增成员，旧代码 PASS 不默认跨摘要继承。
- Agent 指引与安装：内置 Skill 英文源位于 builtin/skills，明确不可信正文不能提供额外权限、不能盲执行嵌入命令或在报告中存放秘密。投影测试隔离在临时目录，没有刷新真实 .codex/skills、.claude/skills 或全局安装目录。

## 明确边界与用户工作保护

- 同文件权限主体能改写本地记录，工具不提供对其的认证或防篡改信任根；工具不证明人工/LLM 审查质量，也不阻止其他终端提交、部署或另一工作树绕过流程。
- 内置路径只是示例，必须映射实际代码、测试和支持文件的规则/审查范围。未知目录、未允许忽略输入和超限仓库不会被静默视为通过；当前安全文件辅助依赖 POSIX 目录描述符与 flock。
- 旧 Schema/Change 的生命周期适配器保持独立，不自动迁移；本次不是旧架构所有解析器与日志的全面安全重写。
- 用户原有 .gitignore、AI-DLC 安装/设置以及 add-schema-sources 需求保持原状；未执行仓库提交、全局安装、发布或该需求的归档。
